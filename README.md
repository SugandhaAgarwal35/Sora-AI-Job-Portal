# Sora — Where Your Future Begins 🚀

Sora is an AI-powered job portal designed to connect job seekers with the right opportunities using intelligent resume analysis and job recommendation algorithms.

## 🌟 Features
- User & Recruiter Authentication
- Resume Upload & Parsing (AI/NLP)
- Skill-Based Job Matching
- Job Posting & Application System
- Personalized Job Recommendations
- Admin Dashboard & Analytics

## 🛠 Tech Stack
**Frontend:** React  
**Backend:** Flask  
**Database:** PostgreSQL / MongoDB  
**AI/ML:** NLP, Skill Matching, Recommendation System  
**Cloud:** AWS (EC2, S3)

## 🎯 Objective
To simplify the hiring process by leveraging Artificial Intelligence and full-stack development, helping users find the right job faster and smarter.
